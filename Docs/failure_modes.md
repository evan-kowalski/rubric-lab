# Rubric Evaluation Failure Modes

This document describes common failure modes observed during evaluation workflows, along with concrete examples and mitigation strategies.

## Ambiguous Criteria

Subjective criteria without clear boundaries lead to inconsistent evaluator scoring.

Example:
A criterion stating that an output should be reasonably comprehensive lacks an explicit standard. Evaluators may diverge significantly on required depth.

Mitigation:
Define measurable requirements such as necessary sections, minimum structural elements, and specific factual assertions.

## Missing Anchor Points

Scales that lack representative examples make calibration difficult across different score levels.

Example:
A rubric provides a scale from one to five but defines only the extremes. Evaluators must guess how intermediate quality maps to middle scores.

Mitigation:
Provide concrete exemplar responses and detailed score descriptors for every point on the scale.

## Scorer Disagreement Patterns

Evaluators often differ in strictness or interpret ambiguous edge cases differently.

Example:
One evaluator penalizes minor typographical errors heavily, whereas another ignores them and evaluates only core content.

Mitigation:
Conduct calibration sessions prior to evaluation runs, document consensus on edge cases, and monitor inter-rater reliability.
